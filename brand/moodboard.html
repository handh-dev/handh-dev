01 / name

Two spellings. That's all.

Always lowercase. The .dev is part of the name. No initials, no nicknames, and never the ampersand character, anywhere.

✓display name
handh.dev

Headlines, body copy, page titles, alt text, bios, signatures, legal lines.

✓slug
handh-dev

Repos, packages, file names, code identifiers, URL paths, handles where a dot isn't allowed.

05 / shape

Every shape comes from the mark.

Four motifs, nothing else. No blobs, waves, sparkles, glass or gradients.

Outer round, inner square

Pairs get 24px 0 0 24px and 0 24px 24px 0. Solo cards use 16px.

The seam

A thin gap, not a line. 2 to 8px between joined blocks.

64°

The cut

One diagonal at 64°. Clipped corners, dividers, wipes. One per view.

The stem

A vertical bar for quotes, callouts, active states, timelines.

08 / logo

Use the files. Don't touch them.

Clear space equals the width of the ink stem on every side. Minimum 24px for the mark in UI, 96px wide for the full lockup. The lockup is stacked, so headers and navs use the brandmark alone.

✓Full color on white or ink-50
✓Reversed file on ink-950 / ink-800
✓Mono white on brand blue
✓Clear space: one stem width
✕Stretch, squash or skew
✕Recolor or swap colors
✕Rotate, shadow, glow, 3D
✕Busy or mid-tone backgrounds

10 / for agents

Hand over these files.

This page is the picture. The files are the rules.

  • brand/BRAND.md: full spec, rules and checklist. Read first.
  • brand/tokens.json: every value, machine-readable.
  • brand/tokens.css: drop-in CSS variables, light and dark.
  • brand/assets/: the only approved logo files. *-tight.svg = cropped lockups for headers.
  • brand/check-brand-name.py: name and ampersand linter.
  • brand/moodboard.html: this page.
Prompt to give any agent"Read brand/BRAND.md and brand/tokens.json before you start. Follow them exactly. Use logo files from brand/assets only. Run brand/check-brand-name.py on your output and fix anything it flags."
